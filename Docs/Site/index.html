MapView

Reusable view

Retained vector geography, camera bindings, markers and routes in a native terminal view.

The recording replays fixed OpenFreeMap world and street XYZ tiles over local HTTP through the real MapTileLoader. It demonstrates coverage, loading, retry, annotations and detail changes; static previews show minimal detail. Replay inputs and data credits.

The command below opts into current OpenFreeMap acquisition. Omit --online for bundled offline geography. A writable raw-tile cache reuses fresh responses; immutable tile packs retain offline data without expiry or network fallback.

Download recording ↓

Try this example

Map API and usage ↗ 
swift run -c release chio-maps --online --map street

For an offline world pack, run swift run -c release chio-maps --write-tile-pack .build/world.chiomap once, then swift run -c release chio-maps --tile-pack .build/world.chiomap. This uses bundled coarse world tiles and the programmatic pack API; it does not download street data.

Arrow keys pan · + / − zoom · e retries online acquisition · n / p select and center a location · Return activates · Tab moves native focus · [ / ] lower/raise detail · d cycles levels · Space switches world/street · t changes theme · f switches outlines/fills · l toggles labels · r resets · q quits. Minimal is the default; use --detail silhouette, abstract or source to start elsewhere.

Use in your view

API guide ↗

source: MapSource and overlays: MapOverlays are retained inputs; camera: MapCamera and selection: String? are application-owned bindings.

MapView(source: source, camera: $camera, selection: $selection,
        overlays: overlays, detail: .minimal)
    .mapFills(true)
    .frame(width: 100, height: 26)
    .chioTheme(.default)

Presentation options. Detail: minimal, silhouette, abstract or source. Fills or outlines and labels are separate options; source zoom chooses input resolution, while theme chooses paint.

Map acquisition and storage. MapTileLoader · MapTileCache · MapTilePack — explicit, application-owned opt-ins beside the view.

Native drawing, text labels, layout and keyboard input.

API guide ↗

agents and capabilities are application-owned Identifiable models with name fields; selection is an optional agent ID and selectedIDs is a set of capability IDs.

VStack {
    SearchableList(agents, selection: $selection, searchText: \.name) {
        Text($0.name)

Share shortcut descriptions between compact hints and an expanded native help presentation.

Press ? while browsing or F1 during editing to open grouped help. Closing returns to the retained control and query; typing ? in search remains text. All run actions update a local counter.

API guide ↗

navigation: [ShortcutHint] contains your descriptions. Native handlers register the actions; these views only present them.
