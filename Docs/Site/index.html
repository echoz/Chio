Take it for a spin.

From a checkout of Chio, with Swift 6.4+ on macOS 15+ or Linux.

$ swift run -c release chio-dashboard

Open the run history example directly:

$ swift run -c release chio-dashboard --pagination

Explore the native viewport or nested folders:

$ swift run -c release chio-dashboard --viewport
$ swift run -c release chio-dashboard --tree

Try grouped settings and inline validation:

$ swift run -c release chio-dashboard --forms
