World and street vectors, in the terminal

Component example

Compose Chio’s MapView with your own camera, locations and routes. Opt into online world and street maps: panning loads neighboring tiles through the explicit MapTileLoader, retaining the last accepted coverage during loading or failure. Press e to retry; eligible responses can be reused from the memory cache. Add --tile-cache .build/map-cache to reuse fresh raw tiles across launches in a bounded, source-specific disk cache. For durable offline data, supply a read-only MapTilePack through the same loader and memory cache; its tiles do not expire or get evicted from storage. Visual detail stays independent of source zoom. World and street views use the same online tile pipeline. Select a location with n or p and press Return to activate it. Braille location rings and cleared routes keep annotations legible; press f to switch filled areas to outlines at any detail level.

The recording and static previews replay fixed OpenFreeMap XYZ tiles at source zooms 1 and 12 over local HTTP through the real MapTileLoader. This repeatable fixture session demonstrates world and street coverage, loading, retained coverage, retry, markers, routes, detail changes and themes. Static previews show the default minimal level. The command below discovers current OpenFreeMap tiles; omit --online for the offline default. Replay inputs and data credits ↗.

Download recording ↓

Try this example

Map API and usage ↗ 
swift run -c release chio-maps --online --map street

For an offline world pack, run swift run -c release chio-maps --write-tile-pack .build/world.chiomap once, then swift run -c release chio-maps --tile-pack .build/world.chiomap. This uses bundled coarse world tiles and the programmatic pack API; it does not download street data.

Arrow keys pan · + / − zoom · e retries online acquisition · n / p select and center a location · Return activates · Tab moves native focus · [ / ] lower/raise detail · d cycles levels · Space switches world/street · t changes theme · f switches outlines/fills · l toggles labels · r resets · q quits. Minimal is the default; use --detail silhouette, abstract or source to start elsewhere.

Chio
MapView, MapTileLoader, opt-in MapTileCache, MapTilePack, OpenMapTilesSource, checked camera and geography, location markers, route overlays and shared themes.
SwiftTUI
Native drawing, text labels, layout and keyboard input.
Application
Network opt-in, retained source and coverage status, camera and selection bindings, location annotations, authored routes and activation feedback.
